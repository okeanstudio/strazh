# Вклад в Strazh

Спасибо за интерес к проекту. Для изменений:

1. Создайте отдельную ветку и pull request с кратким описанием проблемы и
   решения.
2. Не добавляйте реальные ключи, пароли, токены, пользовательские данные,
   production-конфигурации и собранные приложения. Для примеров используйте
   вымышленные значения.
3. Перед отправкой выполните:

   ```sh
   flutter pub get
   flutter analyze
   flutter test
   ```

4. Для изменений аутентификации, криптографии, политик Supabase или обработки
   push опишите последствия для приватности и обратной совместимости.
5. Не публикуйте сведения об уязвимости в issue; следуйте инструкции в
   [политике безопасности](SECURITY.md).

Отправляя вклад, вы соглашаетесь с тем, что он распространяется на условиях
[GNU AGPL-3.0](LICENSE).
