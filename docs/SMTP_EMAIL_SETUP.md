# Настройка SMTP для смены email

Endpoint `server/send_email_change_code.php` отправляет коды подтверждения через
SMTP. Задайте настройки в окружении PHP-сервера; не храните пароль в исходном
коде или репозитории:

- `SMTP_HOST` — SMTP-сервер (по умолчанию `mail.okeanstudio.ru`);
- `SMTP_PORT` — порт (по умолчанию `465`);
- `SMTP_ENCRYPTION` — `ssl` для порта 465 или `tls` для STARTTLS, обычно порт 587;
- `SMTP_USERNAME` — имя пользователя из панели почтового провайдера; обычно это
  полный адрес ящика, например `no-reply@okeanstudio.ru`;
- `SMTP_PASSWORD` — пароль этого почтового ящика;
- `SMTP_FROM_EMAIL` — адрес отправителя (по умолчанию равен `SMTP_USERNAME`);
- `SMTP_FROM_NAME` — имя отправителя (по умолчанию `Strazh`).

Настройте переменные для PHP-FPM/веб-сервера, который обслуживает endpoint, и
перезапустите соответствующий сервис. Значения, заданные только в shell-сессии
SSH, могут быть недоступны PHP-FPM. Используйте актуальные SMTP-сервер,
логин, пароль, порт и тип шифрования из панели провайдера; доступность хоста
сама по себе не подтверждает корректность SMTP-учётных данных.

Если появляется ошибка авторизации, проверьте, что `SMTP_USERNAME` — именно
SMTP-логин (часто полный адрес ящика), а `SMTP_PASSWORD` — пароль ящика или
специальный пароль приложения. После замены учётных данных, ранее хранившихся
в исходном коде, смените старый пароль у почтового провайдера.
